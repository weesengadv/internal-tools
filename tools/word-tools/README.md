# LetterForm v0.1.0 — 立体字制作工具

备案日期：2026-10-16。Windows 本地浏览器版本，尚未打包为独立 EXE。

## 用途

导入 DXF 字形，制作立体字底板与围墙，设置螺丝洞、出线洞、亚克力切割轮廓，导出 STL 和 DXF。几何处理运行在本机 Python 服务中，默认地址 http://127.0.0.1:8765/。

## 当前版本功能

### 1. DXF 导入及二维检查

- 导入闭合字形轮廓，无需预先画内墙线或螺丝洞。
- 支持多段线、圆、椭圆、样条及块内轮廓等；未闭合线、未转轮廓文字及歧义会提示检查。
- 确认 DXF 内线是参考线、真实内洞或螺丝洞；输出前确认分类。
- 全部尺寸以 mm 处理；无单位图纸需要核对实际尺寸。

### 2. 三种制作方式

1. 不加墙：保留底板及原有内洞，总厚度等于底板厚度。
2. 加墙，没有内洞：填平原有字形内洞，生成外墙；螺丝洞保留。
3. 加墙，有内洞：保留字形内洞，生成外墙与内洞围墙。

墙厚可调；向内偏移保留外形尺寸，向外偏移增加尺寸。默认墙厚 0.8 mm、底厚 1 mm、总高 30 mm；可改为输入底板以上墙高。

### 3. 螺丝洞

- 设置洞径、边距，系统按字形尺寸、笔画面积和洞径估算 1–50 个洞，或自定义数量。
- 自动数量为几何建议，实际数量受可用空间限制；需要时手动调整。
- “重排选中字母螺丝洞”按当前设置替换选中字母洞位，支持 Undo。
- 手动加洞无需先选字母，开启后点击任意可见字母实体区域即可。
- 选中洞可拖动、修改 X/Y，或按 Delete / 删除按钮删除；输入框内 Delete 仅编辑数字。
- Reset 恢复所选部件的洞位基准；手动删除的洞不会在普通生成时擅自恢复。
- 相同形状和尺寸、洞位兼容的字母可联动移动/删除；不兼容洞位需明确应用整套洞位模板。

### 4. 出线洞

- 独立开关，默认直径 6 mm，可修改；每个独立部件通常 1 个。
- 橙色显示，可移动、删除、重排，或取消特定部件的出线洞。
- 自动避开围墙、字形内洞及螺丝洞；空间不足提示调整。
- 穿过底板，包含在 Body DXF 的 WIRE_HOLES 图层及 STL 中；不穿亚克力盖板。

### 5. 亚克力与导出

- 总间隙默认 0.2 mm，即每侧 0.1 mm；盖沿默认从插入轮廓向外延伸 1 mm。
- 亚克力 DXF 分 ACRYLIC_INSERT 与 ACRYLIC_TOP 图层，供后续 CNC 工艺处理。
- 当前只定义平面轮廓，未生成带真实亚克力厚度/加工深度的三维 T 形盖板。
- Body DXF 可单独导出；STL ZIP 包含所有部件 STL、参考总布局、body.dxf、适用时的 acrylic.dxf、参数和部件清单。
- 无墙模式不生成 T 形亚克力轮廓，ZIP 内附说明。
- 单个字母 3D 预览；ZIP 导出全部部件。导出时检查孔位冲突，重新读取 STL 检查封闭性和正体积。

### 6. 编辑与界面

- 右侧顺序：字壳 → 螺丝洞 → 出线洞 → 亚克力。
- 右键/中键拖动平移，左键拖框选多个字母，滚轮缩放，显示全部。
- 左键拖动洞位仍编辑洞位置；Shift/Ctrl 支持追加选择。
- Undo / Redo；保存与打开 .letterform.json，保留图形、设置和手动洞位。

## 使用流程

1. 导入 DXF 并检查内线分类。
2. 设置制作方式、墙厚、螺丝洞、出线洞和亚克力轮廓。
3. 点击 Generate 2D；需要改已有螺丝洞时点击“重排选中字母螺丝洞”。
4. 手动检查/调整洞位，先处理红色冲突。
5. 可直接导出 DXF；或进入 Generate 3D 设置底厚、总高并预览。
6. 导出 STL + DXF ZIP；保存项目 JSON 方便再次修改。

## Windows 启动

当前电脑：双击 start-letterform.cmd。启动器会打开本机浏览器；使用期间保留服务窗口。

另一台电脑：先安装 Python 3.11 或以上并包含 Python Launcher，运行 setup-letterform.cmd 一次安装依赖，再运行 start-letterform.cmd。首次安装需要网络。压缩包包含编译界面，正常使用不需要 Node.js。程序不是无需安装环境的 EXE。

## 已知范围

- 中文拆开的笔画按独立部件处理，不自动合并为一个逻辑汉字。
- 三维预览当前以单个部件为主；完整打印床排版、大字切分、盖板三维装配、多种结构样式尚未实现。
- LetraMaker 研究中的功能并不属于本版本；研究笔记单独存放，未复制进产品功能。
- 任意来源的 DXF 可能有歧义，制作前需检查尺寸与轮廓。

## 包内容与备案

源码：src、backend、worker、scripts、tests；编译程序：dist；启动脚本；说明及测试记录。

不包含 node_modules、虚拟环境、缓存、Git 工作目录、用户生产图纸及试制 STL。Git 历史另以 bundle 备份；备案 ZIP 的具体 commit 和 SHA-256 见同目录发布清单。

## 开发与验证

- 安装前端依赖：npm ci
- 编译前端：npm run build
- 后端测试：python -m pytest backend/tests -q
- 编辑及视图测试：node --test tests/project.test.mjs tests/viewport.test.mjs
- 交互检查：node scripts/verify-components.mjs
- 站点兼容测试：npm run test:sites
