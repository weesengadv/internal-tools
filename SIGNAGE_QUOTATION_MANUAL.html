AI Signage Quotation User Guide

This guide explains how to configure the AI Signage Quotation tool and how staff should use it for daily quotation work.

Owner/admin setup Staff workflow Google Sheet pricing AI recognition

What This Tool Does

The Signage Quotation tool helps quote signage with two main parts: backing and emboss words. The user provides one real-world reference size, AI recognizes the words and alphabet dimensions, and the system calculates pricing from Google Sheet data.

AI Recognition

Detects grouped words, individual alphabet boxes, width, height, and confidence after a backing/guideline size is provided.

Deterministic Pricing

The app calculates prices from Google Sheet rates. AI helps recognize and draft notes, but pricing is not guessed by AI.

First-Time Configuration

  1. Copy signage-config.example.json and rename the copy to signage-config.json.
  2. Fill in baseUrl, model, and either apiKey or the Windows environment variable SIGNAGE_AI_API_KEY.
  3. For a simple one-tab setup, fill googleSheetCsvUrl with the published Google Sheet CSV URL.
  4. For a full quotation workbook, fill googleSheetId and googleSheetTabs with each tab name and gid.
  5. Keep signage-config.json private. It is ignored by git and should not be committed.
  6. Restart the server after changing config: node server.js.
Important: Do not paste your real API key into screenshots, GitHub, or shared manuals. Use SIGNAGE_AI_API_KEY if possible.

AI Model/API Setup

The local server uses GET /api/signage/pricing for Google Sheet rates, then calls an OpenAI-compatible chat completions API through POST /api/signage/recognize and POST /api/signage/draft.

  • baseUrl: API base URL, for example https://api.openai.com/v1.
  • model: model name used for photo recognition and quote draft.
  • apiKey: optional local key. Prefer SIGNAGE_AI_API_KEY for safer setup.
  • alphabetLibrary: extra notes for the AI about alphabet detection rules.
  • recognitionPrompt: instruction text used when recognizing signage photo dimensions.
If AI config is missing, the app uses sample recognition so staff can still learn the workflow.

Daily Quotation Workflow

  1. Open Quotation > Signage Quotation.
  2. Upload signage/building photo, or click Sample for training.
  3. Enter the guideline or backing size in inches.
  4. Use the Guideline or Backing box tool to mark the known size on the photo.
  5. Click Re-run AI with correction to run recognition.
  6. Review detected alphabet dimensions in the table.
  7. Select emboss material/model and lighting: front lit, back lit, or no lit.
  8. Correct wrong detections by editing table dimensions or typing a correction prompt.
  9. Repeat AI correction until the quote is correct.
  10. Use Print / PDF or Save quote as PNG.

How To Correct AI Mistakes

Edit Table Values

Change a letter, width, or height directly in the AI Detection Review table. The quote recalculates after edits.

Type A Correction Prompt

Example: Letter S height is 18 inch. Use backing width as 144 inch and recalculate.

Redraw Backing Box

Use the Backing box tool when the AI backing area is wrong or the photo perspective is confusing.

Manual Shape Fallback

Use rectangle/pen fallback when AI cannot recognize a special shape or unclear alphabet.

How LED And PSU Are Calculated

If lighting is front lit or back lit, the app adds LED and PSU line items. If lighting is no lit, LED and PSU are not added.

  • LED watts = number of detected letters x ledWattPerLetter.
  • LED cost = LED watts x ledCostPerWatt.
  • Usable PSU watts = psuWatt x psuUsableFactor.
  • PSU quantity = LED watts / usable PSU watts, rounded up.

Print/PDF And Save As PNG

  • Print / PDF opens the browser print dialog. Choose a printer or save as PDF.
  • Save quote as PNG downloads a customer-ready quotation image.
  • Review dimensions, material, lighting, LED, PSU, and total before sending to customer.

Troubleshooting

Problem What To Check
AI always returns sample result Check signage-config.json, API key, baseUrl, model, then restart node server.js.
Google Sheet prices not used Make sure the sheet is published as CSV and googleSheetCsvUrl is filled correctly.
Prices look wrong Check the CSV keys, numeric values, lighting selection, and whether the area is in sqft.
AI dimensions are wrong Confirm the guideline size, redraw the reference line/backing box, then rerun AI with a correction prompt.
PSU not added Check lighting mode. PSU is only added for front lit or back lit.
