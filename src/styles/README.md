# Styles

Root `styles.css` imports these files in order so the current single-page app keeps working.

Files:
- `base.css`: app shell, navigation, top bar, shared controls
- `gcode.css`: G-code settings and text editors
- `stl-viewer.css`: STL viewer panels and canvas
- `signage.css`: signage workflow, canvas, quote UI
- `print.css`: printable signage quotation
- `responsive.css`: mobile layout overrides
